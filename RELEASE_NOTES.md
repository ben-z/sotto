Sotto v0.1.10 makes release checksum filenames consistent across macOS and iOS.

- Each download has its own matching `.sha256` file, generated by its build.
- The macOS checksum is now named `Sotto-0.1.10-macOS-universal.zip.sha256`.

## Downloads

- **Sotto-0.1.10-macOS-universal.zip** contains the app for Apple Silicon and Intel Macs running macOS 14+. This personal-use build is ad-hoc signed and is not Apple-notarized. See the README for installation steps.
- **Sotto-unsigned.ipa** contains the iPhone and iPad app for iOS 17+ and requires signing and provisioning before installation.
- Each package has a matching `.sha256` file. Download the package and its checksum into the same directory, then run `shasum -a 256 -c <filename>.sha256` to verify it.

Release CI attaches these files after all required checks pass.
